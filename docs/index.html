kokoro-pi

Kokoro text to speech on a Raspberry Pi 5, about twice as fast on the same CPU. The point of the exercise is that you cannot hear the difference — so here it is to listen to.

github.com/zreecespieces/kokoro-pi

Same text, same voice, three builds

All produced on one Raspberry Pi 5 with the voice af_heart, on held-out text the int8 calibration never saw. Upstream is the published Kokoro ONNX export. Float adds graph rewrites and a native Snake kernel — 1.35×, and identical to 115 dB. int8 adds the fused convolution kernel and is the default build: 1.83× on the vocoder, and what you are listening for is whether it costs anything.

These are 64 kbit MP3s so the page loads on a phone; the originals are 24 kHz WAVs in samples/. In a blind listen over all six held-out utterances, none of the builds was distinguishable from the float engine, which is why the default is the fastest one. The measured gap is 2.2 dB log-spectral distance against a floor of roughly 1 dB for any change at all — why that is the right measure.

Running it

curl -fsSL https://raw.githubusercontent.com/zreecespieces/kokoro-pi/main/install.sh | bash

curl -s http://127.0.0.1:8080/v1/tts -H 'Content-Type: application/json' \
  -d '{"text":"Hello from my Raspberry Pi."}' | aplay -q -r 24000 -f S16_LE -c 1 -

It speaks the OpenAI speech API and the Wyoming protocol as well, so Open WebUI and Home Assistant need a URL and nothing else.

Kokoro-82M is by hexgrad, Apache 2.0. The ONNX export is kokoro-onnx. This project is MIT and redistributes no model weights — they are downloaded and verified at install time.
